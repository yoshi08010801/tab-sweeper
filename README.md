# 🧹 Tab Sweeper

A lightweight Chrome extension that helps you clean up browser tabs quickly and efficiently.

## 🚀 Features

- Close tabs by domain
- Save and restore tab sessions
- Automatically organize open tabs
- Minimal, simple UI

---

## 🛠 Installation (Local development)

1. Clone this repository  
2. Open Chrome → `chrome://extensions/`
3. Enable **Developer mode**
4. Click **"Load unpacked"**
5. Select this project folder

## 🧹 Tab Sweeper とは？

Tab Sweeper は、ブラウザに増えすぎたタブを素早く整理するための軽量 Chrome 拡張機能です。  
右クリックメニューから操作でき、複雑な設定は不要です。

---

## 📌 機能

- ドメインごとにタブを一括で閉じる  
- 現在開いているタブ構成（セッション）を保存・復元  
- 開きすぎたタブを自動整理  
- シンプルで分かりやすい UI  

---

## 🛠 インストール（開発版）

1. このリポジトリを clone  
2. Chrome を開き `chrome://extensions/` にアクセス  
3. **デベロッパーモード** を ON  
4. **「パッケージ化されていない拡張機能を読み込む」** を押す  
5. このプロジェクトフォルダを選択
